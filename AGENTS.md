# Agent guidance

- Product scope or user-experience work: read `docs/product.md`.
- Domain naming or behavior changes: read `CONTEXT.md`.
- Selection sharing, privacy, lifecycle, or agent integrations: read
  `docs/architecture/selection-bridge.md` and
  `docs/research/agent-compatibility.md`.
- Architectural changes: read the relevant record under `docs/adr/`.

## Agent skills

Issues live as GitHub issues in `ZhengHe-MD/contexture`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, used verbatim as label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
