# Contexture

Contexture is a macOS-first Markdown editor that lets writers share the exact
text they select with the AI agent they already use. The editor stays focused
on writing: conversations remain in Codex, Claude Code, Gemini CLI, GitHub
Copilot, Antigravity, or another compatible agent host.

The project is currently in product-definition and architecture-design stage.

## Product promise

Select Markdown in Contexture, switch to a compatible agent, and submit a
prompt. The selected Markdown is added to that prompt's model context. If
nothing is selected, Contexture adds nothing.
